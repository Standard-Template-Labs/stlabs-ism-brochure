# STLabs — Intelligent Service Management (2-pager)

Marketing brochure for STLabs' Intelligent Service Management platform.

## Files

- `index.html` — the 2-page brochure (open directly in a browser)
- `axiom-live-graph.html` — the Axiom live-graph visual, embedded via iframe on page 1
- `inbox-ticket.png` — screenshot used in the page-2 Inbox spotlight

## Viewing

Open `index.html` in any modern browser. For best fidelity, view in Chrome and use print-to-PDF at Letter size, no margins, background graphics on.
